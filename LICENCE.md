## 🧩 About

**Warframe Companion** is a curated list of Warframe open-source tools:

- **Overlays** — on-screen helpers, layout notes, damage meter, resource tracker
- **Quality-of-Life Helpers** — inventory catalog, build manager, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Mission Helpers
- Resource Tracker — track rare resources and drops
- Show Enemy Markers — visualize enemy positions
- Mission Timer — track mission progress and objectives
- Speed Control — adjust game speed for study (0.1x to 5x)

### 🎨 Arsenal & Cosmetics
- Build Catalog — browse and organize loadouts
- Mod Manager Notes — plan mod configurations
- Custom UI Notes — organize interface elements

### 🏋️ Practice Layout
- Training Mode Notes — practice movement and abilities
- Gravity Control — adjust gravity for study
- Jump Buffer Notes — chain complex maneuvers in the dojo
